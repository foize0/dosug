# Досуг

Учебное приложение для поиска бесплатных городских мероприятий и публикации встреч.

Открыть: https://foize0.github.io/dosug/

Афиша, поиск и фильтры, публикация, редактирование, завершение и удаление своих встреч. Один профиль может иметь только одно актуальное объявление. Данные демонстрации хранятся в браузере на конкретном устройстве.

Здесь размещены только публичные файлы веб-версии.
